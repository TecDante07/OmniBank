# Tarea 3. Dictamen sobre `saldo_actual`

El saldo actual es un dato derivado del historial de operaciones y, por ello, puede generar redundancia e inconsistencias si se actualiza sin coordinación con las transacciones. No obstante, conservar un agregado derivado no constituye automáticamente una dependencia transitiva ni una infracción formal de 3FN: esta forma normal estudia dependencias funcionales entre atributos de una relación. La observación del auditor es válida respecto al riesgo de duplicar información calculable, pero no es rigurosa al afirmar que necesariamente viola 3FN.

Con un historial de 250,000 operaciones, calcular `SUM()` en cada consulta puede incrementar el trabajo de CPU, las lecturas y la latencia, especialmente bajo muchas solicitudes simultáneas. Se recomienda mantener `saldo_actual` como agregado materializado deliberado para consultas frecuentes, siempre que se actualice junto con el movimiento correspondiente dentro de una transacción ACID, usando bloqueo de fila (`SELECT ... FOR UPDATE` o `UPDATE` atómico) y, cuando proceda, triggers cuidadosamente diseñados. Se deben añadir controles de conciliación periódicos contra el historial para detectar diferencias. Así se prioriza el rendimiento sin renunciar a la integridad contable.
